"""
Примеры: админка «Зоомагазин» (Django admin).

1) Создание суперпользователя (интерактивно)
   cd <корень проекта LR5>
   source .venv/bin/activate   # при необходимости
   export DJANGO_SETTINGS_MODULE=zooshop.settings
   python manage.py migrate
   python manage.py createsuperuser
   Введите username, email (опционально), пароль.

2) Суперпользователь без запросов (для CI / dev)
   python manage.py createsuperuser --noinput \
     --username admin --email admin@example.com
   Пароль из переменной окружения (Django 5+):
   export DJANGO_SUPERUSER_PASSWORD='secure-password-here'

   Либо команда проекта:
   python manage.py bootstrap_superuser
   (читает BOOTSTRAP_SUPERUSER_USERNAME, BOOTSTRAP_SUPERUSER_EMAIL,
   BOOTSTRAP_SUPERUSER_PASSWORD; не перезаписывает существующего пользователя.)

3) Вход в админку
   Запустите сервер: python manage.py runserver
   Откройте в браузере: http://127.0.0.1:8000/admin/
   Войдите под суперпользователем.

4) Главная страница админки
   Вверху отображается блок «Статистика магазина» (заказы, выручка, активные товары,
   отзывы, низкий остаток, поставщики) и «Быстрые ссылки» на товары, категории,
   заказы, поставщиков, закупки.

5) Товары: превью и фильтры
   Раздел «Catalog» → «Products».
   В списке колонка «Фото» — миниатюра изображения (если загружено поле image).
   Справа фильтры: категория, поставщик, активность, возрастное ограничение, удалённые.
   Поиск по названию, SKU, описанию.

6) Связи поставщиков с товаром
   На карточке товара: вкладки «Product stock» и «Product supplier links» (инлайны).
   Либо отдельно: «Product supplier links» для массового редактирования связей.

7) Действия (actions) в списках
   Выберите строки галочками → в выпадающем списке «Action» выберите, например:
   - Products: «Сделать активными», «Soft-delete выбранных», «Восстановить выбранные».
   - Orders: «Статус: отгружен», «Статус: отменён».
   - Reviews: «Опубликовать» / «Снять с публикации».
   Нажмите «Go».

8) Autocomplete
   При редактировании заказа поля «customer», «created by», «promo code» подсказывают
   значения при вводе (нужны search_fields у связанных моделей — уже настроены).

9) Медиа-файлы (картинки товаров)
   В режиме DEBUG файлы отдаются с префикса MEDIA_URL (см. zooshop/urls.py).
   Убедитесь, что каталог media/ доступен для записи при загрузке изображений.

10) Права staff
    Доступ к /admin/ имеют пользователи с is_staff=True.
    Суперпользователь (is_superuser) видит все модели независимо от permissions.
